# worship-helper-api
Api do aplicativo worship helper

## Assistente ao vivo

Defina `AUDD_API_TOKEN` para habilitar o reconhecimento de trechos de audio enviados pelo app enquanto uma cifra de evento esta aberta. O assistente consulta primeiro as musicas cadastradas na igreja e, quando nao encontra correspondencia, retorna uma cifra temporaria encontrada automaticamente.
